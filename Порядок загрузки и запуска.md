# Порядок загрузки и запуска

Инструкция для того, кто ставит приложение с нуля. Знать про проект ничего не
нужно — всё необходимое ниже. Работает и в Беларуси, и в России.

## Зачем это

Приложение само обходит белорусские тендерные площадки и отбирает закупки,
которые подходят «Промтехснабу»: отливки, поковки, штамповку, запчасти к
насосам, редукторам, конвейерам. Крупные заводы вроде БМЗ и Гомельского
химического закупают за собственные средства, в бюджетную систему такие закупки
не попадают вовсе — и это самое интересное, что оно находит.

Разложено на пять шагов: поставить, запустить, проверить площадки, собрать,
посмотреть результат. Займёт примерно час, из которого почти всё — ожидание
сбора.

---

## 1. Что поставить заранее

**Python 3.11 или новее** — https://www.python.org/downloads/
При установке обязательно отметьте галочку **«Add Python to PATH»** на первом
экране. Её легко пропустить, а без неё ничего не запустится.

**Git** — https://git-scm.com/download/win — всё по умолчанию.

**Редактор** — любой из двух, что вам привычнее:
- VS Code — https://code.visualstudio.com/ , после установки добавьте
  расширение **Python** (значок кубиков слева → найти «Python» от Microsoft);
- PyCharm — https://www.jetbrains.com/pycharm/download/ , бесплатной Community
  версии достаточно.

## 2. Забрать проект и подготовить его

Откройте **Командную строку** (Win+R → `cmd` → Enter) и выполните по очереди:

```
cd %USERPROFILE%\Documents
```

```
git clone https://github.com/ivanovich1071/Tender-PTS.git
```

```
cd Tender-PTS && python -m venv .venv && .venv\Scripts\python.exe -m pip install -r requirements.txt
```

Последняя команда идёт минуту-две и заканчивается словами вроде
`Successfully installed …`. Если так — подготовка закончена.

### Ключ модели — по желанию

Лоты отбираются в два уровня: сначала правила по словам, потом модель, которая
решает по смыслу. Второй уровень нужен затем, что «поддон деревянный» и
«поддон печи закалочной» пишутся одинаково, а нужен только второй.

Модель работает через OpenRouter и требует ключа. Если он у вас есть — откройте
файл **`.env`** в корне проекта (он заводится сам при первом запуске) и впишите
его в единственную строку:

```
OPENROUTER_API_KEY=sk-or-v1-…
```

Файл `.env` в репозиторий не отправляется и в журнал не попадает.

**Ключа нет — ничего страшного.** Сбор пройдёт полностью, лоты будут помечены
«моделью не проверено», и разбирать список придётся руками. Ключ можно вписать
позже, в самом приложении: Настройки → «Отбор моделью».

## 3. Открыть в редакторе и запустить

Конфигурации запуска уже лежат в проекте, набирать команды не придётся.

### VS Code

1. **Файл → Открыть папку** → выберите `Tender-PTS`. Именно папку, не файл.
2. `Ctrl+Shift+P` → наберите `Python: Select Interpreter` → выберите строку с
   пометкой **`.venv`**. Это делается один раз и это ключевой шаг: без него
   будет ошибка «No module named fastapi».
3. Слева значок **«Запуск и отладка»** (`Ctrl+Shift+D`), сверху в списке
   выберите **«Приложение»** и нажмите `F5`.

### PyCharm

1. **Open** → выберите папку `Tender-PTS`.
2. PyCharm сам предложит подхватить окружение — согласитесь. Если не предложил:
   **File → Settings → Project → Python Interpreter** → шестерёнка →
   **Add Interpreter → Add Local Interpreter → Existing** → укажите файл
   `Tender-PTS\.venv\Scripts\python.exe`.
3. Справа сверху в списке конфигураций выберите **«Приложение»** и нажмите
   зелёный треугольник (`Shift+F10`).

### Если что-то не так с редактором

Приложение прекрасно запускается и из командной строки, в папке проекта:

```
.venv\Scripts\python.exe -m app
```

В любом случае должен открыться браузер на `http://127.0.0.1:8770`. Если не
открылся сам — зайдите по этому адресу вручную.

## 4. Что сделать в приложении

### Шаг первый: проверить площадки — **скриншот 1**

Кнопка **«Настройки»** в правом верхнем углу → пролистать до раздела
**«Площадки»** → кнопка **«проверить площадки»**. Проверка идёт до минуты.

Ожидаемый результат — все четыре строки зелёные, «отвечает». Именно это и надо
снять.

Если какая-то строка красная — это тоже важный результат, снимайте как есть:
по нему видно, какая площадка не открылась и почему. Приложение при этом
работает дальше, просто соберёт меньше.

### Шаг второй: собрать тендеры — **скриншот 2**

Закройте настройки, нажмите синюю кнопку **«Собрать тендеры»**.

Сбор идёт **20–40 минут** — приложение обходит сотни страниц и нарочно делает
паузы, чтобы не долбить площадки. В шапке видно, что происходит прямо сейчас.
Можно свернуть окно и заняться своими делами, прерывать не надо.

Когда закончится, в шапке появится строка вроде
«48 лотов · ГИАС 4 из 11 · icetrade 31 из 260 · 512 запросов». **Снимите её
вместе со списком найденного слева.**

### Шаг третий: открыть любой лот — **скриншот 3**

Щёлкните по любой строке списка. Справа откроется карточка: заказчик, сроки,
суммы, лоты, документация, контакты. Снимите её целиком.

### Шаг четвёртый: скачать документацию — **скриншот 4**

В карточке, в разделе **«Документация»**, нажмите **«скачать всё»**. Напротив
файлов должно появиться «скачан». Снимите этот момент.

Потом **нажмите «открыть» хотя бы на одном PDF и на одном DOC** и убедитесь,
что файл действительно открылся. Это важнее всего остального: до сих пор
площадка иногда отдавала вместо документа свою главную страницу, и приложение
записывало её на диск под именем `.pdf`. Теперь оно такой ответ отвергает и
пишет в статусе, что вернулась страница. **Если увидите такой статус — снимите
его**, это ровно то, что нужно проверить.

Если получится — повторите ещё для двух-трёх лотов, особенно тех, где в имени
файла есть похожее на название детали: `shesternya-56.jpg`, `val-97.pdf`. Это
чертежи, они нужнее договоров.

### Шаг пятый: посмотреть вкладку «Мимо профиля» — **скриншот 5**

Наверху, рядом с «Новые» и «Все», есть вкладка **«Мимо профиля»**. Туда
уходит то, что не подходит предприятию: заказчик правильный, а предмет чужой —
огнеупорные смеси, контакторы, счётчики воды. Загляните и снимите.

Ничего оценивать не нужно, просто покажите, что там оказалось. Если увидите
там что-то явно металлическое и сделанное по чертежу — отметьте это в письме,
такие промахи разбираются отдельно.

> На вашем запуске отбор моделью, скорее всего, выключен: ключ хранится в
> настройках и в репозиторий не попадает. Тогда лоты будут помечены
> «моделью не проверено» — это нормально, так и должно быть.

## 5. Что прислать обратно

| Что | Где взять |
|---|---|
| Пять скриншотов из пункта 4 | как получились |
| Файл журнала | папка `Tender-PTS\work\logs\`, самый свежий файл |
| Папка `Tender-PTS\work\docs\` | архивом, если скачалась документация |

**Журнал — самое важное.** В него пишется всё, что делало приложение, включая
то, чего на экране не видно. Путь к нему показан в настройках, в самом низу, в
разделе «Журнал» — оттуда его можно скопировать.

Ключи и пароли в журнал не попадают, пересылать его безопасно.

## 6. Если что-то пошло не так

**«python не является внутренней или внешней командой»** — Python ставился без
галочки «Add Python to PATH». Переустановите, отметив её.

**«ModuleNotFoundError: No module named 'fastapi'»** — запускается системный
Python вместо проектного. В VS Code выберите интерпретатор с пометкой `.venv`
(пункт 3.2), в PyCharm — укажите путь к `.venv\Scripts\python.exe`.

**Браузер не открылся** — зайдите руками на `http://127.0.0.1:8770`.

**«Сбор» ничего не находит или ругается** — так тоже бывает, и это ценные
сведения. Пришлите журнал, там будет причина.

**Приложение зависло на одной строке дольше пяти минут** — нажмите «Отменить»,
пришлите журнал.

В любой непонятной ситуации: **пришлите файл журнала целиком.** По описанию
«не работает» причину не найти, а по журналу — почти всегда.
