# Что запустить, пока вы в Беларуси

Главное: **находясь в Беларуси, прокси не нужен вообще.** Обе закрытые площадки —
`icetrade.by` и `goszakupki.by` — режут доступ по региону, а с белорусского
адреса открываются напрямую. Поэтому поездка заменяет аренду прокси и позволяет
сделать то, что снаружи невозможно.

Поездка ограничена по времени, поэтому порядок задач выстроен от главного к
второстепенному. Если успеете только первые три пункта — этого уже достаточно.

---

## 0. Подготовка (сделать заранее, дома)

Возьмите ноутбук, на котором проект уже развёрнут и работает. Проверьте дома,
что запускается:

```
cd /d "C:\Users\Dell\Documents\GitHub\20-08 Tender"
```

```
.venv\Scripts\python.exe -m app
```

Должен открыться браузер со списком лотов. Если открылся — всё готово, везите
как есть.

### Если поедете с другим компьютером

Понадобится Python 3.11 или новее (при установке отметьте галочку «Add Python
to PATH») и git. Дальше:

```
git clone https://github.com/ivanovich1071/Tender-PTS.git
```

```
cd Tender-PTS && python -m venv .venv && .venv\Scripts\python.exe -m pip install -r requirements.txt
```

База и настройки в репозиторий не входят, так что на новом компьютере всё
начнётся с чистого листа — это нормально.

## 1. Проверить, что вы действительно «изнутри»

Первым делом, ещё до всего остального:

```
.venv\Scripts\python.exe recon\proxy_check.py
```

Без `--proxy` — вы уже в нужной стране, посредник ни к чему.

Ожидаемый ответ:

```
1. Внешний адрес
   ...  страна BY  ...
   Адрес белорусский — то, что нужно.

2. Площадки
    ок   gias.by            ГИАС — работает и без прокси
    ок   goszakupki.by      файлы документации
    ок   icetrade.by        закупки за собственные средства
    ок   zakupki.butb.by    БУТБ
```

**Если страна не BY** — вы через VPN, мобильный интернет иностранного оператора
или корпоративную сеть с выходом за границей. Отключите VPN, попробуйте другую
сеть. Пока страна не BY, остальное бессмысленно.

**Если страна BY, но icetrade всё равно закрыт** — сохраните вывод целиком и
пришлите: значит блокировка не только по региону, и подход надо менять.

## 2. Снять структуру icetrade — ради этого всё и затевается

Это единственное, что нельзя сделать снаружи никак. Площадка закрыта, разметку
взять неоткуда, и без неё разбор писать бессмысленно — получится выдумка.

```
.venv\Scripts\python.exe recon\icetrade_probe.py
```

Скрипт переберёт возможные пути, сохранит ответившие страницы в
`recon\out\icetrade\` и напишет туда `STRUCTURE.md`.

**Что привезти:** всю папку `recon\out\icetrade\` целиком — и `STRUCTURE.md`, и
html-файлы. По ним дописывается разбор.

### Заодно сохраните вручную несколько страниц

Скрипт перебирает пути наугад, и настоящий адрес поиска может в список не
попасть. Поэтому откройте `icetrade.by` в браузере и своими руками:

1. Найдите раздел поиска по закупкам.
2. Задайте поиск по слову **шестерня** (или **отливка**, **теплообменник**).
3. На странице с результатами: правая кнопка → «Сохранить как» → тип
   «Веб-страница, полностью» → положите в `recon\out\icetrade\`.
4. Откройте любую процедуру и сохраните её страницу так же.
5. **Скопируйте адреса из адресной строки** — и страницы поиска, и процедуры.
   Это важнее самих файлов: по ним настраиваются пути в настройках.

Если у процедуры есть приложенные файлы — запишите, как выглядит ссылка на
скачивание.

## 3. Скачать документацию, пока есть доступ

Файлы лежат на `goszakupki.by`, который снаружи закрыт. Пока вы в Беларуси,
их можно забрать — и дальше работать с чертежами уже дома, офлайн.

Запустите приложение:

```
.venv\Scripts\python.exe -m app
```

Дальше в окне браузера:

1. **«Собрать тендеры»** — займёт около десяти минут.
2. Откройте каждый лот и нажмите **«скачать всё»** в разделе «Документация».
3. Убедитесь, что напротив файлов появилось «скачан».

Файлы лягут в `work\docs\`. **Эту папку обязательно привезите** — в репозиторий
она не входит, а чертежи оттуда нужны для следующего шага: чтения массы и марки
стали.

Если лотов окажется много, начните с тех, где в имени файла есть название
детали: `shesternya-56.jpg`, `vodilo-45-stranica-1.jpg` — это чертежи, они
ценнее договоров и протоколов.

## 4. Посмотреть глазами, чего мы не видим

Полчаса ручного просмотра сейчас сэкономят недели догадок потом.

**На icetrade** найдите закупки предприятий из списка наблюдения: Беларуськалий,
Гранит, Доломит, БМЗ, ГродноАзот, Гомельский химический завод, Кузлитмаш, МАЗ,
МТЗ. Ответьте для себя на вопросы:

- Сколько у них открытых процедур прямо сейчас?
- Как называются лоты — номенклатурой или как в ГИАС, «Аукцион»?
- Приложены ли чертежи и в каком виде — PDF, сканы, архивы?
- Нужна ли регистрация, чтобы увидеть документацию, или она открыта?

Последний вопрос ключевой: если документы на icetrade видны только
зарегистрированным, понадобится учётная запись ПТС, и это меняет всю схему.

**На БУТБ** (`zakupki.butb.by`) — то же самое, коротко.

Заметки пишите в свободной форме, хоть в блокнот. Мне нужны факты, а не отчёт.

## 5. Если останется время

- Посмотрите протоколы несостоявшихся процедур Амкодора: за 90 дней 30 из 89
  лотов не состоялись, и причина видна только в протоколе. Если там «не подано
  ни одной заявки» — это прямая точка входа для ПТС.
- Проверьте, есть ли на icetrade выгрузка результатов поиска в Excel или RSS.
  Если есть — разбор HTML не понадобится вовсе, и это лучший исход.

## Если что-то пошло не так

**«python не является внутренней или внешней командой»** — Python не в PATH.
Переустановите с галочкой «Add Python to PATH» либо запускайте полным путём.

**Ошибка про путь с файлом** — вы не в папке проекта. Сначала `cd /d "C:\...\20-08 Tender"`,
кавычки обязательны: в имени папки пробел.

**«ModuleNotFoundError: No module named 'fastapi'»** — запускаете системным
Python вместо проектного. Нужно именно `.venv\Scripts\python.exe`, не `python`.

**Сбор идёт и ничего не находит** — нормально, если у Амкодора сейчас нет
открытых процедур. Загляните в настройки и увеличьте «глубину сбора» до 60–90
дней: увидите больше, хотя часть будет с истёкшим сроком.

**Приложение не открылось в браузере** — зайдите руками на `http://127.0.0.1:8770`.

Если застрянете — сохраните текст ошибки целиком и пришлите. По одной строке
«не работает» я не угадаю.
