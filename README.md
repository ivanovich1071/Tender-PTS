# Tender-PTS

Отбор тендеров Республики Беларусь по профилю ООО «Промтехснаб».

Приложение само проходит белорусские площадки по номенклатуре компании,
отсеивает неактуальное и выкладывает оператору карточку лота: предмет закупки,
сроки, заказчика, документацию и чертежи, живые ссылки на процедуру. Решение об
участии принимает человек — система доводит только до оценки.

## Запуск

```bash
python -m app
```

Откроется браузер на `http://127.0.0.1:8770`. С флагом `--window` то же самое
живёт в отдельном окне (нужен `pywebview`). Наружу приложение не слушает.

Первый запуск:

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python -m app
```

## Как это работает

**Источник — ГИАС (`gias.by`).** У сайта есть внутренний JSON API без
авторизации: поиск по закупкам и карточка с лотами, сроками и списком
приложенных файлов. Официальной документации нет, контракт снят с сетевых
запросов самого сайта, поэтому форма ответа проверяется явно и при расхождении
сбор падает громко — см. `app/sources/gias.py`.

**Отбор идёт по лотам, а не по названию закупки.** Самые крупные лоты названы
«Аукцион» или «Закупка из одного источника», а деталь видна только внутри:
«Объемная штамповка из стали "Вал шестерня" №97». Дополнительный сигнал — имена
приложенных файлов: площадка переименовывает их в транслит
(`val-shesternya-97.jpg`), и по имени видно деталь, не открывая файл.

**Актуальность — жёсткий фильтр.** Лот со сроком подачи меньше двух рабочих
дней в список не попадает вообще. Рабочие дни считаются по календарю РБ:
праздники и переносы задаются в настройках текстом, потому что объявляются
постановлением на каждый год.

**Заказчики под наблюдением.** 19 крупных предприятий машиностроения,
металлообработки, химии и горнодобычи — от Амкодора и БМЗ до Беларуськалия и
Нафтана. Их закупки называются «Аукцион», деталь видна только внутри лота,
поэтому берутся целиком и фильтруются стоп-словами.

**Документы качаются через сервер, а не браузером.** Браузер оператора ходит
напрямую и о прокси приложения не знает, поэтому ссылка «на площадке» упирается
в блокировку. Кнопка «скачать» тянет файл через тот прокси, который задан в
настройках, кладёт в `work/docs/` и дальше открывает уже локальную копию.

## Что известно про доступ к площадкам

Замерено 20.08.2026 с адреса вне Беларуси:

| Хост | Что отдаёт | Вывод |
|---|---|---|
| `gias.by` | работает | данные и метаданные берутся без прокси |
| `goszakupki.by` | таймаут | файлы документации без прокси не скачать |
| `icetrade.by` | 403 на любой путь + неполная цепочка сертификата | нужен белорусский прокси |
| `zakupki.butb.by` | работает | источник ещё не написан |

**ГИАС — это только бюджетная сфера.** Крупные заводы закупают за собственные
средства, а это icetrade. У БМЗ в ГИАС 100 закупок за шесть лет (тепловизоры,
дизтопливо), у Гомельского химического последняя — за 2023 год. Поэтому
icetrade для ПТС важнее ГИАС, и без прокси видна лишь часть рынка.

Проверка расширения словаря показала то же самое: из 43 формулировок
(«изготовление по чертежам», «дробилка запасные части», «горно-шахтное
оборудование» и прочие) 34 дали ноль актуальных лотов. Поток в ГИАС тонкий не
из-за узкого профиля, а по состоянию рынка.

## Структура

```
app/
  sources/gias.py   источник ГИАС: поиск, карточка, разбор
  profile.py        профиль компании, транслитерация
  matching.py       отбор по номенклатуре, поставка против работы
  calendar_by.py    рабочие дни РБ, фильтр актуальности
  collector.py      сбор целиком
  store.py          SQLite
  server.py         HTTP, только 127.0.0.1
  web/              интерфейс без сборки
profile.json        номенклатура ПТС, стоп-слова, заказчики
recon/              разведка: скрипты и отчёт по рынку
tests/              проверки календаря и отбора
```

## Профиль

`profile.json` — словарь предметной области, правится текстом. Собран по архиву
реальных заказов ПТС за 2024–2026 и выверен прогонами по ГИАС: одиночные слова
из имён чертежей («ступица», «шнек», «гребенка») в поиске по госзакупкам не
работают — тащат автозапчасти и бытовую технику, поэтому оставлены только
различающие словосочетания.

## icetrade

Адаптер `app/sources/icetrade.py` написан, но **разбор страниц не подтверждён**:
площадка закрыта для всех адресов, с которых он писался, и снять реальную
разметку было неоткуда. Пока `structure_confirmed` в настройках выключен,
источник честно отказывается работать, а не выдаёт выдумку за данные.

Чтобы его включить, с машины с доступом к площадке:

```bash
python recon/icetrade_probe.py --proxy socks5://user:pass@host:port
```

Скрипт перебирает возможные пути, сохраняет ответившие страницы в
`recon/out/icetrade/` и пишет `STRUCTURE.md` с подсказками по разметке: формы,
поля поиска, шаблоны ссылок на процедуры, признаки JSON API. По этому снимку
дописывается разбор и правятся пути в настройках.
